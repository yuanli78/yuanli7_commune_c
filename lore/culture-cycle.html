🔄 文化循环论

作品不是物，而是流通的过程

一、打破“作品是物”的错觉

很多人认为作品是一个静态的“物”，可以像商品一样被个人永远占有。但我要打破这个印象：作品跟资本一样，是运动的过程。个人作品只不过是作品流通过程中的一个阶段。

作品不断从公共领域转变为创作物，再转变为阅读物，再转变回公共领域。而版权法阻碍了这最后一步——作品的流通过程被人为中断了。

二、版权公有化的文化循环公式

P(公共领域) → C(创作物) → R(阅读物) → P'(集体公共领域)
版权公有化下的文化循环公式

版权公有化应当是这样的流程：公共领域转变为创作物，再转变为阅读物，最后转变到集体公共领域。如此一来，便能阻断资本对个人的侵占——因为作品始终在集体手中流动，资本无处下手。

三、对比：被版权法打断的循环

在私有版权制度下，循环是断裂的：

P → C → R → ⛔ 私有版权囤积 → 无法回归公共领域

资本通过囤积版权，将本应回归公共领域的文化成果占为己有，并向后来者收取“过路费”。文化循环论揭示了这一过程的非正义性。

四、作品是流通的过程，不是物

重申：作品并不是物，而是流通的过程。只有恢复完整的文化循环，让创作成果不断反哺公共领域，集体创作才能持续繁荣。

五、粉丝制：打断文化循环的毒瘤

当代的文化生产身上正挂着一颗大毒瘤——粉丝制。它将各个领域的文化生产者异化成商品的同时，也在批量制造个人崇拜。在粉丝制度下，各类饭圈文化是其必然带来的结果之一。

这种现象最早出现于影视圈，原本靠作品质量生产的模式逐渐发生偏移：片酬开始两极分化，越高者粉丝越多，片酬就越多。为了支付高额片酬，原本用于作品质量方面的投入必然向这种支付转移，最终导致作品越来越烂。带来的直接恶果之一，就是偶像塌房时粉丝坚决维护——哪怕明知这个人做错了，他们仍然这么做，因为这个偶像是他们的商品。

这不是影视圈的孤立现象。2026年6月的三角洲清雨事件，有人吃黑流量一直不肯改名，有人伪装成完美受害者形象，口口声声答应过要把所有收入捐款，可完成粉丝积累过后，转头就暴露出了投机分子的真实面目。网文圈中刺猬猫平台的百合后宫大战，导致两个类型的很多作品被封禁，这也是粉丝制度恶行的体现。

粉丝制度在哪个环节打断了文化循环？

C(创造物)质量过低 → R(阅读物)跟随下降 → P(公共领域)质量下滑 → C质量更低

粉丝制度使文化生产的逻辑从"作品质量→获得受众"扭曲为"制造偶像→收割粉丝"。作品质量不再决定作品命运，粉丝数量才是。这导致了C阶段——创造物的质量持续下滑。当创造物质量下降，读者受众必然跟随下降，进而使公共领域的文化整体质量下滑，反过来又拉低了下一轮创造物的质量。这是一个恶性循环。要打断这个循环，就不能只停留在表层，必须废除粉丝制度。

我们应该坚定地反对这种制度，不能再让人成为一种商品。在我们自己的平台上，粉丝数量坚决不能被显示出来。观看数、点赞数、收藏数也不应默认显示，而是让用户主动去找。取消这些数字本身，就是在切断粉丝制度在平台层面的生存土壤。
