⚠️ 论"科幻共产主义"式的错误路线

CC 不是集体版权、多 IP 不是一体化、大纲不是生长

核心结论：某吧出现了一份"科幻共产主义"世界观的召集令，方向是对的、热情是真的——但路线是错的，而且错在最要命的地方。它要走 CC 开源路线（保留个人著作权）、要搞覆盖平行宇宙的多 IP、要先立一份世界观大纲。这三样恰好对应公社一路批判的三条错路。

一、事件：一份召集令

那份召集令的内容大意是这样：

  • 要打造一个属于无产阶级文化领域的"IP"——一套有理论支撑的世界观大纲；
  • 覆盖平行宇宙类小说／漫画、科幻题材小说／漫画的创作；
  • 命名为"科幻共产主义"，这个 IP 将是开源的，属于每一位无产阶级劳动者；
  • 你可以写故事、画角色、修订设定；也可以做理论注释、审校逻辑；
  • "我们需要舵手，也需要笔杆子，更需要旗手"。

下面按路线逐条批。先说清楚：这不是骂人，是批路线。他们是同志，走错了路，而路线的对错不因为谁走的而改变。

二、先肯定：方向是对的，热情是真的

在他们那封信里，有几句话是对的：

  • "既然极右翼已经证明科幻小说是传播思想的极为有效的工具，那么左翼阵营也应当拥有自己的科幻作品"——这个判断完全正确。科幻是左翼该拿下的阵地；
  • "这本质上是一场文化阵地上的斗争"——对；
  • "属于每一位无产阶级劳动者"——这个愿望是好的。

问题不在愿望，在方法。而方法错了，愿望越好，损失越大——因为它会把一批有热情的人引到一条走不通的路上，消耗掉他们本来能做出东西的时间。

三、第一个致命问题："开源"≠"版权归集体"

看到"这个 IP 将是开源的"，路线问题就已经暴露了。

先讲准一个技术事实：CC（知识共享）这类协议并不转让著作权——它只是在著作权框架内，授予他人使用的许可。每个创作者仍然是自己作品的所有权人。

所以问题不是"放弃版权"，而是更麻烦的一件事：

CC 把版权"个人化"了——人人保留自己那一份。
而在资本主义条件下，分散的版权＝可以逐个收买。

想象一下资本会怎么做：它不需要买下整个项目，它只需要找出其中最有价值的几个人，把他们的独立创作权买断或者挖走——因为每个人都合法地拥有自己作品的所有权，所以他有权卖，也有权走。

于是"开源"的最终结果不是壮大，是瓦解：最有价值的那部分人被资本挑走，剩下的散作一地。

另一个更根本的问题：开源是"无差别开放"。

  • 对同志开放，也对资本开放；
  • 而资本恰恰有更强的加工能力、渠道和变现手段——它拿了开源内容就能赚钱，而我们拿它没办法；
  • 所以"开源"在资本主义条件下，最大的受益者往往不是劳动者，是资本。

公社的方案是"版权归集体"：作品的所有权转移给集体，个人保留署名、荣誉与劳动报酬。这样一来——

没有任何一个个体能卖掉集体的东西。
所以集体版权是不可收购的。

这不是理论问题，是武器问题。参见公约第三原则（版权归集体）与《论公社金为什么抄不走》。

四、第二个致命问题：多 IP 不是一体化

那句"能够覆盖平行宇宙类小说／漫画"——这句最危险。

"覆盖平行宇宙类"是什么意思？意思是：每个人写自己的宇宙，用同一个协议互联。听起来很开放，实际上等于——

一百个小宇宙，不是一个宇宙。

多 IP 路线（他们）一体化 IP 路线（公社）
结构许多人各写各的宇宙，用协议互联所有人写同一个宇宙
结果一百个小世界观，各有各的天花板一个装得下所有人的容器
对抗资本用一百个小宇宙，去打资本的一体化宇宙用一体化对一体化
长期趋势没有统一核心，必然分裂越写越厚，越写越大

看第三行：资本做的是什么？是漫威、是星球大战——一个宇宙、几十年的作品、上千个角色。你要拿一百个独立的小宇宙去对抗这种一体化巨物，必输。

而"平行宇宙"这个设定本身，恰恰是多 IP 路线的技术掩护：

"每个宇宙都是合理存在的，所以你的设定和我的设定可以共存。"

——共存是共存了，但永远长不成一个整体。这就像"全世界无产阶级联合起来"变成了"每个国家的工人各自成立一个组织，然后互不隶属"。

参见《论文艺路线》里关于"共产主义文学只需要一部 IP、必须以宇宙为尺度"的论述。

五、第三个致命问题："世界观大纲"

信里写得清清楚楚："一套有理论支撑的世界观大纲"。

大纲。——这正是公社明确反对的东西（参见《论大纲是违反共产主义的产物》）。

为什么？因为大纲思维的本质是从结局倒推：先想好世界是什么样，再让人往里填内容。而创作的实际情况恰恰相反——

世界是在写的过程中长出来的，不是在写之前画好的。

而更要命的是这个流程设计：先造大纲 → 再召集大家来"修订设定"。

这是什么？这是自上而下的规划式创作：少数人定框架，多数人填内容。它把创作变成了"施工"——图纸早就画好了，群众只是工人。

公社的方式正好相反：没有大纲。你现在能读到的这一百多篇理论与设定，没有一篇是先有蓝图再写的——它们是一篇一篇长出来的，后面的问题逼出前面的答案，前面的答案又逼出后面的问题（参见《论世界观为什么会自己长大》）。

两种方式的区别：
他们是"先画图纸，再召集工人"；
我们是"先动手做，图纸在过程中长出来"。

六、第四个问题："舵手"和"旗手"

信里有一句："我们需要舵手，也需要笔杆子，更需要旗手。"

这句话听起来很有感召力，但它的结构是：有人掌舵，有人划桨。

  • 舵手——决定方向的人（少数）；
  • 笔杆子——干活的人（多数）；
  • 旗手——露脸的人（少数）。

"舵手"这个比喻本身就是等级结构：船上只有一个舵手，其余都是水手。而公社的立场是——

没有舵手，只有同志。
方向不是一个人决定的，是集体在讨论和实践中逐步确认的。

这不是抠字眼。一个组织怎么称呼自己的成员，就会怎么对待他们。叫他们"笔杆子"，他们就是工具；叫他们"同志"，他们才是主人。

七、这场斗争的本质：自由主义路线 vs 集体主义路线

把上面四条合起来，其实只有一条分歧：

自由主义路线集体主义路线
版权各人保留自己的（靠 CC 等协议协调）归集体（靠公约与制度统一）
联合方式自愿联合——想来就来，想走就走组织起来——有纪律、有底线、有约束
世界观多 IP 并存一体化
决策舵手定方向集体定方向

这不是新问题，是老问题。第一国际时期就有过同样的斗争：一派主张自由联合、反对集中（蒲鲁东、巴枯宁那一系），一派主张组织起来、反对散漫（马克思那一系）。历史已经给过一次答案了。

而你预见的那句是准的：

日后集体创作这块，走妥协自由主义路线还是走集体主义路线的斗争，一定会显现出来。

其实它现在就已经显现了——只是它还披着"开源""开放""属于每一位劳动者"这些好听的词，还没撕破脸。等到要分版权、要决定听谁的、要面对资本收购的时候，这场斗争就会摆到桌面上。

（而这正是《论世界观为什么会自己长大》里说的：矛盾是定义的副产品——你定义了"开源"，就同时定义了"版权归个人"，斗争从那一刻就埋下了。）

八、我们该做什么：三条

  • 第一，不要去踢馆。跑到人家帖子底下开骂，只会让对方从"路线错误"变成"受委屈"，还会把一批本来能争取的人推到对面。批路线，不批人（参见《论前期主攻方向》第八节）。
  • 第二，把道理做成文件。他们缺的不是热情，是一份讲清楚"为什么版权必须归集体、为什么必须一体化、为什么不能用大纲"的材料。这一篇就是；以后有人来问，直接给文章。争论一次做完，然后变成文件。
  • 第三，用实践说话。最有力的回应不是反驳他们的计划，是拿出一部真正长出来的、一体化的、版权归集体的作品。到那时候不用争——两条路的结果自己会摆出来。
他们画的是图纸，我们种的是树。
三年之后，图纸还是图纸，树已经结果了。

九、结论

五句话：

  • 方向对，路线错——他们要拿下科幻阵地是对的，方法是错的；
  • 开源不是集体版权——CC 保留个人著作权，结果是分散的版权可被逐个收买，而无差别开放的最大受益者往往是资本；
  • 多 IP 不是一体化——一百个小宇宙打不过资本的一个一体化宇宙，而且没有统一核心必然分裂；
  • 大纲不是生长——"先定大纲再召集大家修订"，是自上而下的规划式创作，把群众当施工队；
  • 斗争的焦点是版权与路线——自由主义路线 vs 集体主义路线，这个斗争一定会显现出来。

看一个集体创作计划行不行，只需问三件事：
版权归谁？是一部还是多部？谁定方向？
