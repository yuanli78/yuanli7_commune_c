⚠️ 论"科幻共产主义"式的错误路线

CC 不是集体版权、多 IP 不是一体化、大纲不是生长

核心结论：某吧出现了一份"科幻共产主义"世界观的召集令，方向是对的、热情是真的——但路线是错的，而且错在最要命的地方。它要走 CC 开源路线（保留个人著作权）、要搞覆盖平行宇宙的多 IP、要先立一份世界观大纲。这三样恰好对应公社一路批判的三条错路。

一、事件：一份召集令

那份召集令的内容大意是这样：

  • 要打造一个属于无产阶级文化领域的"IP"——一套有理论支撑的世界观大纲；
  • 覆盖平行宇宙类小说／漫画、科幻题材小说／漫画的创作；
  • 命名为"科幻共产主义"，这个 IP 将是开源的，属于每一位无产阶级劳动者；
  • 你可以写故事、画角色、修订设定；也可以做理论注释、审校逻辑；
  • "我们需要舵手，也需要笔杆子，更需要旗手"。

下面按路线逐条批。先说清楚：这不是骂人，是批路线。他们是同志，走错了路，而路线的对错不因为谁走的而改变。

（后来又拿到了他们自己世界观里的设定文本——见第六之三节。如果那是他们的正史，那么下面批的每一条，都已经在他们自己的设定里长出来了。）

二、先肯定：方向是对的，热情是真的

在他们那封信里，有几句话是对的：

  • "既然极右翼已经证明科幻小说是传播思想的极为有效的工具，那么左翼阵营也应当拥有自己的科幻作品"——这个判断完全正确。科幻是左翼该拿下的阵地；
  • "这本质上是一场文化阵地上的斗争"——对；
  • "属于每一位无产阶级劳动者"——这个愿望是好的。

问题不在愿望，在方法。而方法错了，愿望越好，损失越大——因为它会把一批有热情的人引到一条走不通的路上，消耗掉他们本来能做出东西的时间。

三、第一个致命问题："开源"≠"版权归集体"

看到"这个 IP 将是开源的"，路线问题就已经暴露了。

先讲准一个技术事实：CC（知识共享）这类协议并不转让著作权——它只是在著作权框架内，授予他人使用的许可。每个创作者仍然是自己作品的所有权人。

所以问题不是"放弃版权"，而是更麻烦的一件事：

CC 把版权"个人化"了——人人保留自己那一份。
而在资本主义条件下，分散的版权＝可以逐个收买。

想象一下资本会怎么做：它不需要买下整个项目，它只需要找出其中最有价值的几个人，把他们的独立创作权买断或者挖走——因为每个人都合法地拥有自己作品的所有权，所以他有权卖，也有权走。

于是"开源"的最终结果不是壮大，是瓦解：最有价值的那部分人被资本挑走，剩下的散作一地。

另一个更根本的问题：开源是"无差别开放"。

  • 对同志开放，也对资本开放；
  • 而资本恰恰有更强的加工能力、渠道和变现手段——它拿了开源内容就能赚钱，而我们拿它没办法；
  • 所以"开源"在资本主义条件下，最大的受益者往往不是劳动者，是资本。

公社的方案是"版权归集体"：作品的所有权转移给集体，个人保留署名、荣誉与劳动报酬。这样一来——

没有任何一个个体能卖掉集体的东西。
所以集体版权是不可收购的。

这不是理论问题，是武器问题。参见公约第三原则（版权归集体）与《论公社金为什么抄不走》。

四、第二个致命问题：多 IP 不是一体化

那句"能够覆盖平行宇宙类小说／漫画"——这句最危险。

"覆盖平行宇宙类"是什么意思？意思是：每个人写自己的宇宙，用同一个协议互联。听起来很开放，实际上等于——

一百个小宇宙，不是一个宇宙。

多 IP 路线（他们）一体化 IP 路线（公社）
结构许多人各写各的宇宙，用协议互联所有人写同一个宇宙
结果一百个小世界观，各有各的天花板一个装得下所有人的容器
对抗资本用一百个小宇宙，去打资本的一体化宇宙用一体化对一体化
长期趋势没有统一核心，必然分裂越写越厚，越写越大

看第三行：资本做的是什么？是漫威、是星球大战——一个宇宙、几十年的作品、上千个角色。你要拿一百个独立的小宇宙去对抗这种一体化巨物，必输。

而"平行宇宙"这个设定本身，恰恰是多 IP 路线的技术掩护：

"每个宇宙都是合理存在的，所以你的设定和我的设定可以共存。"

——共存是共存了，但永远长不成一个整体。这就像"全世界无产阶级联合起来"变成了"每个国家的工人各自成立一个组织，然后互不隶属"。

参见《论文艺路线》里关于"共产主义文学只需要一部 IP、必须以宇宙为尺度"的论述。

五、第三个致命问题："世界观大纲"

信里写得清清楚楚："一套有理论支撑的世界观大纲"。

大纲。——这正是公社明确反对的东西（参见《论大纲是违反共产主义的产物》）。

为什么？因为大纲思维的本质是从结局倒推：先想好世界是什么样，再让人往里填内容。而创作的实际情况恰恰相反——

世界是在写的过程中长出来的，不是在写之前画好的。

而更要命的是这个流程设计：先造大纲 → 再召集大家来"修订设定"。

这是什么？这是自上而下的规划式创作：少数人定框架，多数人填内容。它把创作变成了"施工"——图纸早就画好了，群众只是工人。

公社的方式正好相反：没有大纲。你现在能读到的这一百多篇理论与设定，没有一篇是先有蓝图再写的——它们是一篇一篇长出来的，后面的问题逼出前面的答案，前面的答案又逼出后面的问题（参见《论世界观为什么会自己长大》）。

两种方式的区别：
他们是"先画图纸，再召集工人"；
我们是"先动手做，图纸在过程中长出来"。

顺便说一句"世界观"这个词。有人说：你们不用大纲，可你们不是天天喊"世界观"吗？世界观不就是最大的那个大纲？

不是。"观"是"对……的认识"。世界观是对世界的认识，不是对世界的图纸。认识是从实践里长出来的，所以它可以长、可以改、可以推翻自己；图纸是先画好的，所以它只能被执行、只能被修改、不能被推翻。

静止的是大纲，不是世界观。恩格斯说得清楚：

"世界不是既成事物的集合体，而是过程的集合体。"
——恩格斯《路德维希·费尔巴哈和德国古典哲学的终结》

所以我们说"一体化宇宙"，说的是同一套认识、同一套方法，可以不断地把新东西收进来；不是说"一百年前的设定表已经写完了后面一百年的故事"。前者越长越结实，后者越写越僵死——这恰好也是他们那套方法必然的下场。

六、写作实践不等于理论实践

对方后来又补了一句："我们都是一线写手，我们的理论是从写作实践里来的。"

这句话一半是对的——理论确实只能从实践中来。但它被用错了地方：它是拿来证明"我们不需要先有理论"的。这就把两件事混成了一件。

第一，能写不等于理论扎实。写手写的是"故事里的世界"，理论要回答的是"世界为什么这样运转"。前者是再现，后者是抽象；能把一个人写得活，不等于能说清这个人为什么必然这样活。一线经验是理论的原料，不是理论本身——否则每个工人都自动是马克思主义者了。

第二，顺序被倒过来了。他们说：先拉人开写，理论以后慢慢长。表面上很务实，实际是把唯一的黏合剂留到了最后。没有统一的世界观认识，一百个人写出来就是一百个小宇宙，越写越散；等到发现散了，唯一的补救办法就是"来，我们定个大纲统一一下"——这正是他们必然走到"先定大纲"的原因，不是他们喜欢大纲，是没有别的东西可用了。

公社的顺序是反的：先有一部《公约》、一套共同的世界观认识，然后才开工；而在写作过程中，理论再反过来被实践修改——这就是《论世界观为什么会自己长大》说的那件事。理论是实践的总结，但总结这件事，在开工之前必须先做过一次。哪怕做得粗糙，它也是大家共同的语言。

顺序的差别，就是结局的差别：
他们：先写 → 散了 → 定大纲捆起来 → 创作自由没了；
我们：先有共同认识 → 边写边改认识 → 越写越紧。

六之二、松散组织挡不住资本收编

还有一个更根本的矛盾：他们要"先锋队"的纪律，同时要"开源自由"的散漫。这两个词放在一起是自相矛盾的。

先锋队之所以是先锋队，靠的是四根柱子：纪律、方法论、组织、利益保障（成员的生存和产权由集体兜住）。这四根柱子，他们一根都没有——

  • 纪律：自愿联合、想来就来想走就走，没有纪律；
  • 方法论：没有统一的世界观认识，靠大纲捆，没有方法论；
  • 组织：没有基层组织、没有约束机制，没有组织；
  • 利益保障：版权在个人手里，集体不为成员兜底，没有利益保障。

所以"先锋队"在他们那里是一个形容词，不是一个组织。而一个连纪律都没有的松散联合体，在资本面前是什么状态？下面这张表就是答案：

所以那句"我们都是一线写手"，回答不了资本；能回答资本的，是"你买谁？我们谁都不卖。"

六之三、他们自己的设定：一次踩齐所有的坑

前几节批的是他们的主张——开源、多 IP、大纲。后来又看到了他们自己的设定文本：2100 年、第九共产国际、LP 月度归零、全息大字报、革命倾向性测试、灵魂审计、思想重塑区。

如果这是他们世界观里的正史，那么前面几节预言的"必然发生的事"，已经提前发生了。下面按公社自己的标准，把这份设定过一遍。

第一，词汇层就已经露馅。

  • "柔性的加米巴别公社"——"巴别"是《创世记》第十一章的通天塔。一个自称唯物史观的体系，用圣经地名给自己命名；
  • "灵魂审计"——"灵魂"是宗教词。前面用圣经，后面用灵魂，中间挂着"科学共产主义"；
  • "神秘东方留下的政治遗产"——"神秘东方"是殖民视角的词。一个中国左翼组织把自己的来路叫作"神秘东方"，这是自我他者化；
  • "第九共产国际"——共产国际（第三国际）1943 年 5 月就已解散，没有第四、第五可用，"第九"是凭空编出来的编号；而且"共产国际"本身是各国党的联合体，前提就是有国，跟后面"国家消亡"直接打架。

第二，经济层：这是军营共产主义，不是共产主义。

它写的它的实质
基础配给（合成蛋白、恒温居住、无限带宽）生存线配给

一个号称 2100 年、国家已消亡的共产主义社会，还在用点数 + 月度归零 + 稀缺配额来驱动劳动——这不是消灭了稀缺，是把稀缺管理得更精细。公社的立场正好相反：目标是消除稀缺，不是给稀缺编号。

第三，政治层：用算法和考试代替群众。

  • "革命倾向性测试 + 智力／体力潜能评估"决定社会职能——这是把党性变成入学考试，把先锋队变成筛选机器。等级幻想换了一身数据的外衣。
  • "10% 共鸣共振即强制停权 + 中央算法穿透 + 灵魂审计"——决定权在算法，群众只负责给出一个百分比；
  • "每七年公开一次底层分配算法"——七年一次的公开，是运动式形式主义。

公社的答案不需要算法：批评是群众自己的事，不是阈值的事（见《论前期主攻方向》）。

第四，结构层：自己声明的东西自己拆掉。

  • 说"国界省界彻底抹平""自由人联合体""国家消亡"，转头又保留专区—公社—区—街道—县—镇—乡全套旧行政层级，连"县、镇、乡不变"都写上了。消亡的是名字，留下的是骨架。
  • 编号都乱了：全文出现两个"二、"（"二、积分与消费"与"二、社会形态"），"第九共产国际行政架构示例"悬空，没有上级编号。
  • 内部矛盾：一处说职能按"倾向性测试"分配，另一处说"公社成员会被分配进这些企业内进行劳动"——按考试定岗与按行政分配两条并存。

第五，文艺层：踩的正是我们批过的第三条错路。

1918 + 援共 + 这回援的是德共 + 穿越——这就是《论文艺路线》里点名的那条"援共文·网文投降主义"（另见《论援共文的挂羊头卖狗肉》）。而且时间点自己就挤：德共（KPD）1918 年 12 月 30 日才开成立大会，要"1918 援德共"，窗口只有那两天。

第六，叙事层：它的发动机还是稀缺。

把那套设定里的东西列一遍——LP、基础配给、"非必要需求"、真酿红酒、火星极地观光名额——全是争夺物。一个社会如果还要靠"抢名额"来产生故事，那它设想的 2100 年，只是把今天的超市换成了配给窗口。

这不叫想象力不足，这叫它的世界观里没有量子：它的世界仍然由实体 + 数值构成（配额是实体，LP 是数值），而这正是《论量子力学是集体主义的学科》要封掉的那个前提——关系先于实体。

更深一层的原因：它不敢取消稀缺。一旦稀缺没了，它那套点数管理的整个骨架就塌了——它的想象力，是被它自己的分配制度锁死的（见《论并不存在所谓的后稀缺时代》）。

它不是我们的对手，它是我们的教材。
"科幻共产主义"这条路线的每一个坑——大纲式蓝图、数据化等级、算法代替群众、以稀缺驱动劳动、宗教化词汇——它一次性全踩了。

反过来说，公社的答案一句话就够了：职能不靠考试，靠集体匹配（集体匹配制）；分配不靠点数，靠公有制把稀缺打掉（见《论公有制为什么能耗死资本》）；监督不靠算法，靠群众的日常批评；结构不留旧层级的空壳，要真实的共同体。

两条纪律，说在前面：

① 批路线，不批人。拍死的是这套设定，不是写它的人。里面多半只是没读通的年轻人，不是敌人。

② 归属未定，先把正史钉死。这份材料是从他们群里下载的第一部小说，不排除它不是他们世界观中的正史。所以本节批的是"这套设定本身"；要把定性扩大到整个组织，先钉死"这部作品算不算他们的正史"——这正是《论一体化IP没有盟友》立的规矩：先问归属，再谈边界。

七、第四个问题："舵手"和"旗手"

信里有一句："我们需要舵手，也需要笔杆子，更需要旗手。"

这句话听起来很有感召力，但它的结构是：有人掌舵，有人划桨。

  • 舵手——决定方向的人（少数）；
  • 笔杆子——干活的人（多数）；
  • 旗手——露脸的人（少数）。

"舵手"这个比喻本身就是等级结构：船上只有一个舵手，其余都是水手。而公社的立场是——

没有舵手，只有同志。
方向不是一个人决定的，是集体在讨论和实践中逐步确认的。

这不是抠字眼。一个组织怎么称呼自己的成员，就会怎么对待他们。叫他们"笔杆子"，他们就是工具；叫他们"同志"，他们才是主人。

八、这场斗争的本质：自由主义路线 vs 集体主义路线

把上面四条合起来，其实只有一条分歧：

自由主义路线集体主义路线
版权各人保留自己的（靠 CC 等协议协调）归集体（靠公约与制度统一）
联合方式自愿联合——想来就来，想走就走组织起来——有纪律、有底线、有约束
世界观多 IP 并存一体化
决策舵手定方向集体定方向

这不是新问题，是老问题。第一国际时期就有过同样的斗争：一派主张自由联合、反对集中（蒲鲁东、巴枯宁那一系），一派主张组织起来、反对散漫（马克思那一系）。历史已经给过一次答案了。

而你预见的那句是准的：

日后集体创作这块，走妥协自由主义路线还是走集体主义路线的斗争，一定会显现出来。

其实它现在就已经显现了——只是它还披着"开源""开放""属于每一位劳动者"这些好听的词，还没撕破脸。等到要分版权、要决定听谁的、要面对资本收购的时候，这场斗争就会摆到桌面上。

（而这正是《论世界观为什么会自己长大》里说的：矛盾是定义的副产品——你定义了"开源"，就同时定义了"版权归个人"，斗争从那一刻就埋下了。）

九、我们该做什么：三条

  • 第一，不要去踢馆。跑到人家帖子底下开骂，只会让对方从"路线错误"变成"受委屈"，还会把一批本来能争取的人推到对面。批路线，不批人（参见《论前期主攻方向》第八节）。
  • 第二，把道理做成文件。他们缺的不是热情，是一份讲清楚"为什么版权必须归集体、为什么必须一体化、为什么不能用大纲"的材料。这一篇就是；以后有人来问，直接给文章。争论一次做完，然后变成文件。
  • 第三，用实践说话。最有力的回应不是反驳他们的计划，是拿出一部真正长出来的、一体化的、版权归集体的作品。到那时候不用争——两条路的结果自己会摆出来。
他们画的是图纸，我们种的是树。
三年之后，图纸还是图纸，树已经结果了。

十、结论

八句话：

  • 方向对，路线错——他们要拿下科幻阵地是对的，方法是错的；
  • 开源不是集体版权——CC 保留个人著作权，结果是分散的版权可被逐个收买，而无差别开放的最大受益者往往是资本；
  • 多 IP 不是一体化——一百个小宇宙打不过资本的一个一体化宇宙，而且没有统一核心必然分裂；
  • 大纲不是生长——"先定大纲再召集大家修订"，是自上而下的规划式创作，把群众当施工队；
  • 能写不是理论扎实——写作实践不是理论实践；没有共同认识就开工，散了以后只能靠大纲捆，顺序颠倒必然走到这一步；
  • 松散联合挡不住资本——没有纪律、方法论、组织、利益保障，"先锋队"只是形容词；买断、挖人、抄设定、分裂，一条都挡不住；
  • 斗争的焦点是版权与路线——自由主义路线 vs 集体主义路线，这个斗争一定会显现出来；
  • 他们自己的设定已经替我们证明了一遍——第九共产国际那一套（LP 月度归零、革命倾向性测试、算法穿透停权、灵魂审计），把前面这些错误一次性全摆了出来。

看一个集体创作计划行不行，只需问三件事：
版权归谁？是一部还是多部？谁定方向？
