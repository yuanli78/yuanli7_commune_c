📁 组织概况

核心理念：以火柴的物理结构——火柴棍（形态）与火柴盒侧面（属性擦火）——的二元分离为基础构建能力体系。火柴不再是点火工具，而是"擦火即武器"的驱动器系统。每一根火柴都是一次选择，每一次擦火都是一次战斗决策。

技术路线：实体火柴驱动器。火柴棍上的符号标记决定武器的形态，火柴盒侧面的擦火动作激活属性。二者完全独立、互不绑定，任意形态可搭配任意属性。

标志/象征：一盒火柴 · 擦火即战

社长：安生（在米米尔无限格斗中代表火柴社出战）

知名成员：蜉蝶同志

⚙️ 驱动器机制

火柴驱动器 —— 由一盒火柴构成，内含多根功能不同的火柴棍及一个带擦火侧面的火柴盒。

基本操作：

  • 抽棍：从火柴盒中抽出一根火柴，棍身上的符号标记决定武器形态（剑、盾、手炮等）
  • 擦火：在火柴盒侧面的擦火区一擦，同时选择属性（火焰、水、光、风等），武器即显现
  • 收回：可将火柴收回盒中，随时切换另一根火柴
  • 修复：断裂的火柴可通过量子折叠恢复原状

核心原则：形态与属性完全独立。同一根火柴（剑）搭配不同属性（火焰/水/光），会产生完全不同的战斗效果。同理，同一种属性可以加载在不同的形态上。

🔧 已知形态一览

火柴棍上的符号标记决定武器形态。安生在战斗中已展现的形态包括：

  • 剑火柴——火焰剑。近战基础形态，安生首次使用的武器
  • 盾火柴——可切换无属性防御/火焰融雪/风盾旋转/玻璃纤维盾等多种模式
  • 手炮火柴——远程射击，可发射火焰弹、水流、光炮
  • 棍火柴——近战长柄武器，断裂后可量子折叠恢复
  • 鞭火柴——中距离缠绕/抽打，可搭配光属性
  • 拳套火柴——近战格斗形态
  • 钻头火柴——突破/挖掘形态，可搭配火焰属性释放热能
  • 药火柴——可食用的治愈火柴（呼应"卖火柴的小女孩"中穷人吃火柴的意象）
  • 飞镖火柴——投掷武器，可变为光轮进行多次转向攻击
  • 枪火柴——投掷后可通过风力绕星球一周飞回，实现回马枪战术
  • 追踪弹火柴——自动追踪目标的远程攻击
  • 雷达火柴——无形态探测工具，在烟雾环境中锁定敌人位置

以上仅为安生个人已展现的形态。其他火柴社成员可能持有不同的火柴形态组合。

🔧 已知属性一览

火柴盒侧面的擦火区可选择的属性包括：

  • 火焰——高温灼烧，融雪化冰，制造火焰范围
  • 水——灭火降温，高压水流冲击
  • 光——光能打击，可致盲（光炮爆炸产生的闪光）
  • 风——高速旋转产生热能融化冰雪，也可用于武器回旋加速
  • 电——电流附魔攻击，电磁干扰
  • 玻璃纤维——透明高强度材质，碎片可嵌入敌人体内并被对方吸收利用
  • 治愈——仅在药火柴上使用，可食用并愈合伤势
  • 雷达——仅在雷达火柴上使用，锁定敌人位置
  • 无属性——不附加任何属性，纯物理形态

⚔️ 经典组合实例

以下为安生在战斗中实际使用的组合：

剑 + 火焰 = 火焰剑，近战高温斩击
盾 + 火焰 = 火焰盾，融化冰雪覆盖
盾 + 风 = 风盾，360度旋转吹散雾气
盾 + 玻璃纤维 = 透明玻璃盾，可抵挡并碎裂嵌入敌人体内
手炮 + 火焰 = 火焰弹远程射击
手炮 + 水 = 高压水流灭火
手炮 + 光 = 光炮，爆炸致盲
钻头 + 火焰 = 高温钻头，钻穿冰雪地层
枪 + 风 = 回旋枪，绕星球一周飞回
鞭 + 光 = 光鞭，中距离抽打束缚
棍 + 电 = 电棍，横扫带电击

📜 起源

火柴社的设定灵感来源于安徒生童话《卖火柴的小女孩》。原著中，一个男孩捡走了小女孩跑掉的一只鞋，说要等自己将来有孩子时当摇篮用。在火柴社的改编版起源故事中：男孩主动将另一只鞋归还给小女孩，小女孩送给他一盒普通火柴作为谢礼。次日男孩因与火柴社社员接触被捕入狱，蹲了几年后被送往命运大赛星。在那里与已成为正式社员的女孩重逢，获得了真实的火柴驱动器。

在米米尔无限格斗中登场的是安生——火柴社的代表人物。他继承了"宁可站着死，不肯跪着生"的火柴社精神，在除夕雪夜的擂台上与米米尔展开了激烈对决。

🎯 战术特点

  • 形态切换灵活：抽出一根火柴→擦火→收回→换下一根，切换速度快，可以在一场战斗中频繁变换武器组合
  • 环境利用能力强：善用物理原理（风高速旋转产生热能、水灭火后加剧寒冷等），不是单纯地堆叠元素
  • 消耗品心理：每一根火柴在使用后需要收回，形成"用完即换"的战斗节奏，与数据线的"编织组合"逻辑形成鲜明对比
  • 战术欺骗：雷达+回旋枪的组合展示了火柴社成员善于设计陷阱性的战术组合
